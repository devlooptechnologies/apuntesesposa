# Apuntes de Cultos

## Regla de trabajo

- Después de cada cambio, hacer `git add -A`, `git commit` y `git push` al remoto `origin` (https://github.com/devlooptechnologies/apuntesesposa.git, rama `main`).
- No subir secretos: `.env` está en `.gitignore`. Las credenciales reales van solo en `.env` local.

## Comandos

- Instalar: `npm install`
- Desarrollo: `npm run dev`
- Build: `npm run build`
- Push: `git add -A; git commit -m "mensaje"; git push`
